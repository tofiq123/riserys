# Rise — product roadmap (post-social-layer)

**Date:** 2026-07-20
**Where we are:** Android app fully built + device-verified (alarm engine, missions, wake data, snooze, wake-check); the whole social layer (auth, crew, live status, leaderboard, push/nudges) built + merged; the iOS engine written (needs a Mac compile pass). This roadmap is everything worth adding next, organized into phases.

**Legend — how far I can take each item on this Windows machine:**
- ✅ **full** — Dart/UI, I build + unit/widget-test to green here.
- 🔶 **build-verified** — compiles + reviewed here; real behavior needs the wired backend/device.
- 📱 **device** — needs an on-device pass (camera/sensor/audio/notification).
- 🔑 **accounts** — needs your Supabase Storage / RevenueCat / store setup.
- 🍎 **Mac** — the iOS side needs the compile pass first.

Each phase is independent-ish and shippable on its own. Rough size: **S** ≈ 1–3 tasks, **M** ≈ 4–7, **L** ≈ 8+.

## Phase 6 — Wake Harder: missions & ringtones  ⭐ (the core promise) · size **L**

**Why:** "wake up 100%" lives or dies on how hard it is to cheat the alarm and how good it sounds. This is the strongest single investment.

- **6.1 Real ringtone library** ✅📱 — audit the 5 sound assets (they're likely placeholders); source/replace with real CC0 alarm audio (gentle → aggressive); wire per-alarm selection end-to-end (the picker exists; confirm each plays natively).
- **6.2 Volume fade-in + vibration patterns** ✅📱 — ramp volume over ~30s; per-alarm vibration pattern; "gentle wake" vs "loud" modes. (Native tweak on Android; iOS via the notification.)
- **6.3 QR/barcode mission** ✅📱 — scan a pre-registered code (stick one in the bathroom → forces you out of bed). New dep: `mobile_scanner`. Register-a-code flow in Create/Edit.
- **6.4 Photo mission** ✅📱 — take a photo of a saved spot (e.g. the sink) to dismiss; match by a reference image. Dep: `image_picker`/`camera`.
- **6.5 Shake mission** ✅📱 — shake the phone N times. Dep: `sensors_plus`.
- **6.6 Steps/walk mission** ✅📱 — walk N steps. Dep: `pedometer` (needs activity permission).
- **6.7 Mission tuning** ✅ — math difficulty tiers (harder/multiple problems), longer memory sequences, a typing mission, and **mission chains** (require 2 in a row). Pure Dart — fully testable here.
- **6.8 Mission practice/preview** ✅ — try a mission from Create/Edit before committing.

**Note:** the mission framework (`mission_host`, `mission_frame`) already exists; new missions plug into it. 6.7/6.8 are fully verifiable here; 6.1–6.6 need a device pass.

## Phase 7 — Voice wake-ups (voice clips)  · size **M–L**

**Why:** the deferred social feature — friends record a wake-up message that plays for each other. High emotional hook.

- **7.1 Audio recording** ✅📱 — a record-a-clip UI (≤30s). Dep: `record`.
- **7.2 Storage + RLS** 🔑🔶 — a Supabase Storage bucket for clips + RLS (own-write, crew-read); `voice_clips` table (owner, target, url). SQL you apply.
- **7.3 Playback** ✅📱 — a clip player. Dep: `just_audio`.
- **7.4 Send a voice clip to a crew member** 🔶 — like a nudge but audio; delivered via the existing push + played on open (or set as *their* alarm sound — a "voice alarm gift").
- **7.5 Voice-clip inbox** ✅ — a list of received clips in Crew, with playback.

## Phase 8 — Groups & crew depth  · size **L**

**Why:** turns 1:1 friendships into communities; group accountability is stickier than pairs.

- **8.1 Groups** 🔑🔶 — create/join a named group ("Morning Warriors"); `groups` + `group_members` tables + RLS (member-read, owner-manage). New Crew sub-tab.
- **8.2 Group leaderboard + challenges** 🔶 — rank within a group; a **challenge** (everyone wakes by 7am for 7 days), progress + winner.
- **8.3 Friend detail screen** ✅🔶 — tap a crew member → their profile: streak, on-time %, live status, mutual stats, remove/nudge.
- **8.4 Invite links (deep links)** 🔶📱 — deferred from 5b; a shareable `rise://invite/<code>` that adds a friend/joins a group. Needs deep-link native config.
- **8.5 Activity feed + reactions** 🔶 — "Ada woke up on time 🔥"; react to a friend's wake.
- **8.6 Alarm gifts** 🔶 — deferred from 5d; send a friend a specific alarm/sound to wake to.

## Phase 9 — Stats, insights & achievements  · size **M**

**Why:** the data exists but isn't motivating yet. Retention lever.

- **9.1 Achievements / badges** ✅ — 7/30/100-day streaks, "early bird", "perfect week", "no snooze". Pure Dart, fully testable.
- **9.2 Trends & scores** ✅ — average wake time over weeks, a consistency score, snooze frequency, best/worst days.
- **9.3 Insights** ✅ — computed one-liners ("you wake 20 min earlier on weekdays").
- **9.4 Shareable stats card** ✅📱 — export a stats image to share (viral loop).
- **9.5 Monthly / yearly views** ✅ — beyond the current 30-day/weekly.
- **9.6 Bedtime reminders** ✅📱 — nudge you to sleep in time to hit your wake goal.

Phase 9 is the **most fully-buildable-here** (mostly pure-Dart computation + UI).

## Phase 10 — Onboarding, activation & reliability  · size **M**

**Why:** first-run drop-off + "the alarm didn't fire" (OEM battery killers) are the top churn risks.

- **10.1 Permission priming** ✅📱 — explain *why* before requesting notifications / exact-alarm / battery-unrestricted (higher grant rates).
- **10.2 First-alarm wizard** ✅ — guide the user to set their first alarm in onboarding.
- **10.3 Sleep-goal / schedule setup** ✅ — target wake time + typical schedule; feeds bedtime reminders + insights.
- **10.4 The Setup Guardian** ✅📱 — a reliability screen that checks the phone won't silently kill the alarm (battery optimization, OEM settings, notification channels) and walks the user to fix each. (The permission section exists; this is the guided, OEM-aware version.)
- **10.5 Streak-at-risk reminder** ✅🔶 — "your 12-day streak is at risk — set tomorrow's alarm."
- **10.6 Feature tour** ✅ — surface missions/crew/stats to new users.

## Suggested order

1. **Phase 9 (stats/insights/achievements)** — highest ratio of value to build-here-fully; almost all verifiable on Windows, no accounts/hardware. A great "keep momentum" phase.
2. **Phase 6 (missions & ringtones)** — the core differentiator; the pure-Dart parts (6.7/6.8) now, the device parts when the phone's free.
3. **Phase 12.1 (launcher icon)** — tiny, high-visibility, do anytime.
4. Then **7 (voice), 8 (groups), 10 (onboarding)** as the social/retention layer deepens.
5. **Phase 11 (monetization)** once there's enough premium surface to gate.
6. The **iOS compile pass** whenever a Mac is available (unblocks all device features on iOS).
