# Codemagic iOS builds from Windows (no Mac) — Reference for Plan 2

**Date:** 2026-07-16
**Purpose:** Build/sign/ship the Rise iOS app entirely via Codemagic cloud macOS CI, since the dev machine is Windows with no Mac. Feeds Plan 2 Tasks 13–15.

## Ready-to-adapt `codemagic.yaml`

```yaml
workflows:
  ios-workflow:
    name: iOS Workflow
    max_build_duration: 120
    instance_type: mac_mini_m2          # free-tier M2
    integrations:
      app_store_connect: codemagic      # NAME of the API key in Codemagic Team settings
    environment:
      ios_signing:                      # triggers Codemagic-managed AUTOMATIC signing
        distribution_type: app_store
        bundle_identifier: com.riseapp.rise
      vars:
        APP_STORE_APPLE_ID: 0000000000  # numeric Apple ID of the app record (fill after creating it)
      flutter: stable
      xcode: "26.4"                     # iOS 26 SDK for AlarmKit (current Codemagic default)
      cocoapods: default
    scripts:
      - name: Set up code signing
        script: xcode-project use-profiles
      - name: Get Flutter packages
        script: flutter pub get
      - name: Install pods
        script: find . -name "Podfile" -execdir pod install \;
      - name: Flutter analyze
        script: flutter analyze
        ignore_failure: true
      - name: Flutter build ipa
        script: |
          flutter build ipa --release \
            --build-name=1.0.0 \
            --build-number=$(($(app-store-connect get-latest-app-store-build-number "$APP_STORE_APPLE_ID") + 1)) \
            --export-options-plist=/Users/builder/export_options.plist
    artifacts:
      - build/ios/ipa/*.ipa
      - /tmp/xcodebuild_logs/*.log
    publishing:
      app_store_connect:
        auth: integration
        submit_to_testflight: true
        beta_groups:
          - Internal Testers
        submit_to_app_store: false
```

## How automatic signing works without a Mac

1. Upload **one App Store Connect API key** (`.p8`) to Codemagic once.
2. Declaring `environment.ios_signing` + `integrations: app_store_connect` makes Codemagic run `app-store-connect fetch-signing-files ... --type IOS_APP_STORE --create` — fetches or **creates** the distribution certificate + provisioning profile (generates the cert private key too). No Mac, no CSR.
3. `xcode-project use-profiles` injects them into the Xcode project at build. `/Users/builder/export_options.plist` is generated by the managed setup — do not author it.

**API key** = Issuer ID + Key ID + `.p8` (download once), created in App Store Connect → Users and Access → Integrations (Keys). Give it **App Manager** access. Add to Codemagic under Team settings → Team integrations → Developer Portal → Connect; the name you give it is what `integrations: app_store_connect: <name>` references.

## Xcode / iOS 26 SDK for AlarmKit

- `environment: xcode: "26.4"`. **Xcode 26.x ships the iOS 26 SDK**; Codemagic's default is currently 26.4.x, so AlarmKit compiles out of the box.
- Accepted values: `26.4.1`, `26.4`, `26`, `latest`, `edge`. Pin `26.4`+ for reproducibility.
- Per-version SDK contents: `docs.codemagic.io/specs-macos/xcode-26-4/`; version index: `docs.codemagic.io/specs/versions-macos/`.

## TestFlight → your iPhone

1. App Store Connect → My Apps → + → New App (pick the registered bundle id) → yields the numeric **Apple ID** for `APP_STORE_APPLE_ID`.
2. TestFlight → Internal Testing → new group (name it "Internal Testers" to match `beta_groups`) → add yourself. **Internal testing = up to 100 testers, no Beta App Review**, so builds go live as soon as processing finishes.
3. Install TestFlight on the iPhone; accept invite; install the build.
- Processing: typically **5–30 min** (often ~5–10). Builds testable 90 days.

## Apple-side prerequisites (before build #1)

1. **Apple Developer Program — $99/yr** (confirmed). Apple Account with 2FA.
2. Register **explicit App ID** `com.riseapp.rise` + capabilities.
3. (Only if a widget extension is added later) register `com.riseapp.rise.widget` + App Group.
4. Create the **App Store Connect app record**; note its numeric Apple ID.
5. Generate **App Store Connect API key** (App Manager role); save `.p8`, Issuer ID, Key ID.
6. Create the **TestFlight Internal Testing group**; add yourself.
7. Codemagic: connect the key; name it.
8. Install TestFlight on an **iOS 26 iPhone**.

## Widget extension (only if AlarmKit Live Activities are added — deferred in Plan 2)

Second target, own bundle id `com.riseapp.rise.widget`. Codemagic auto-signing matches profiles by prefix (`com.riseapp.rise.*`) and creates each. Register the extension App ID + App Group if sharing state. **Plan 2 defers the widget/countdown, so this is not needed yet.**

## Cost / time

- **Free tier: 500 macOS-M2 build-minutes/month, personal accounts only.** Resets monthly.
- Extra minutes pay-as-you-go: M2 $0.095/min.
- Typical Flutter iOS build ~8–20 min (budget ~15). 500 min ≈ **~30 builds/month** — fine for steady iteration; use TestFlight's fast internal path rather than rebuilding to re-test.

## Cautions

- Codemagic's default Xcode / `edge` versions rotate — re-check the versions spec page at build time.
- `APP_STORE_APPLE_ID` is the **app record's numeric Apple ID**, not the account email.
- If `--create` fails to register identifiers, elevate the API key role to Admin.
- Physical iPhone is effectively required — the simulator won't exercise real alarm firing / AlarmKit system behavior.
